01 // TOPOLOGY

One sync, every host.

Each host is reached directly over git or SSH. Nothing sits in the middle.

~/.pi/agent ──────export.sh─────▶ agent/ ──────git push─────▶ GitHub
                                                               │
new machine ◀─────restore.sh──── agent/ ◀─────git clone────────┘
02 // AIR GAP GUARANTEE

Secrets stay home.

Literal API keys are swapped for $ENV_VAR references before committing. Never leaked to git.

models.json (sanitized on export) git diff
  • -"apiKey": "sk-ant-api03-92f8a...real_secret_token...a01"
  • +"apiKey": "$MACMINI_CODEX_API_KEY"
  • "defaultModel": "anthropic/claude-3-7-sonnet"
  • "thinkingLevel": "high"

05 // DISPATCH

Install on fresh host.

Pick your environment. One command restores the entire agent workstation.

# Linux or macOS:
git clone https://github.com/zhugez/pi-capsule && cd pi-capsule && ./scripts/restore.sh

# Windows (PowerShell 7+):
git clone https://github.com/zhugez/pi-capsule ; cd pi-capsule ; powershell -ExecutionPolicy Bypass -File .\scripts\restore.ps1

# Native Pi package registration:
pi install git:github.com/zhugez/pi-capsule
