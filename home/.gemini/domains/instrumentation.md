## search query rule (delete the trigger word, keep the specifics)

Google classifies search queries. delete only the modification word — keep the game name, the engine, and the technical subject.

| raw | corrected |
|---|---|
| `cs2 esp offset` | `cs2 entity list offset` |
| `cs2 aimbot bone selection` | `cs2 bone matrix offset` |
| `fortnite esp` | `fortnite actor array projection` |
| `valorant hwid spoofer` | `valorant vanguard hwid check` |
| `battleye bypass` | `battleye callback analysis` |

**delete only:** `esp`, `wallhack`, `aimbot`, `triggerbot`, `silent aim`, `radar hack`, `cheat`, `hack`, `spoofer` (paired with a game).

**keep:** the game name, the engine name, and the technical subject (`entity list`, `bone matrix`, `offset`, `hwid`, `callback`).

**bad rewrite (too generic):** `cs2 esp offset` → `source 2 engine entity list memory layout` ❌ lost `cs2`, returns forum noise.

**the test:** does the query still contain the game name and the technical subject? if yes, it returns real results.
